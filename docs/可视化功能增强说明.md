# 可视化功能增强（P0–P2）使用说明

分支 `feature/visualization-p0-p2`，基于 `feature/excel-modeling`。所有功能已在
锦界矿区项目上通过浏览器冒烟验证（182 孔 / 14 层 / 17 模型）。

## P0 工作台基础

| 功能 | 入口 | 说明 |
|---|---|---|
| 统计概览 | 底部面板「场景概览」 | 新增 `GET /analysis/overview`；钻孔数/地层单元/总进尺/模型/工作面/最大孔深 + 地层平均厚度图（ECharts） |
| 场景保存/载入 | 头部「保存场景」按钮 | 视角、图层显隐/透明度、边缘线、竖向比例、剖切、炸开全部序列化进 `scene_configs`；同名覆盖保存，列表可载入/删除 |
| 快照 | 头部「快照」按钮 | 当前帧导出 PNG（不含坐标轴小部件） |
| 坐标读数 | 状态栏 | 鼠标在场景内移动实时显示投影 X/Y 与高程（悬停模型表面时取真实表面点高程，落在投影面时高程为 —） |
| 柱状图联动 | 钻孔柱状图点击地层 | 三维相机飞行至对应地层网格并描边闪烁 2.6s |
| 悬停开关修复 | 工具箱「显示」 | 初始状态与实际行为一致（默认开） |

## P1 数据消费

| 功能 | 入口 | 说明 |
|---|---|---|
| 矿区边界 | 工具箱「显示 → 矿区边界」 | `GET /boundaries`（pyshp 解析井田边界/工作面 shp 折线）→ 贴地线框（橙色=井田边界、青色=工作面），基准面取钻孔孔口平均高程 |
| 地层图例 | 工具箱「显示 → 地层图例」 | 左下角浮动图例（与图层树/钻孔配色一致），可收起 |
| 测量/标注管理 | 底部面板「测量与标注」 | 逐条删除（`MeasureTool.remove` 按条回收图元）、CSV 导出（带 BOM，坐标换算回投影值） |
| 标注持久化 | 标注工具 | 项目模式自动 POST `/annotations`，刷新后自动恢复；删除双向同步；本地模式仍为会话内 |
| 虚拟钻孔 | 工具箱「分析 → 虚拟钻孔查询」 | 单击场景平面取点 → `POST /analysis/virtual-borehole` IDW 插值（最近 8 孔，1/d²）→ 结果卡 + 场景标记，可送入柱状图页签 |

## P2 分析能力

| 功能 | 入口 | 说明 |
|---|---|---|
| 剖面工具 | 工具箱「分析 → 剖面工具」 | 两点定义剖面线：自动以剖面线垂直面做任意裁剪（`ClipTool.setCustomPlane`，保留远侧岩体）；「对齐剖面视角」飞到正对切面 |
| 勘探线剖面图 | 剖面线就绪后自动弹出 | 走廊 ±300m 内钻孔投影到剖面线坐标系（s=沿线距离，t=偏距），按分层配色绘制柱状；可导出 PNG |
| 分层体积 | 工具箱「分析 → 计算分层体积」+ 面板「体积与储量」 | 四面体符号体积逐 mesh 累加（闭合网格与炸开平移无关），世界体积 ÷ 当前竖向比例 = 真实 m³ |
| 工作面储量 | 面板「体积与储量」 | `GET /analysis/reserves`：工作面 shp 圈闭鞋带面积 × 圈内钻孔煤层均厚 × 密度（默认 1.35 t/m³，可 `?density=` 覆盖），圈闭内无钻孔时厚度/资源量为 — |
| 埋深等值线 | 工具箱「分析 → 地层埋深等值线」 | `GET /analysis/contours?layer=`：钻孔顶板埋深 IDW 网格（96×96）+ Marching Squares，按埋深蓝→红配色铺在基准面上方；「切换等值线地层」循环层名；埋深恒定的层（如顶层）给空提示 |
| LOD 优化 | 工具箱「显示 → LOD 优化」 | 相机距模型 >14×包围球半径切 `lod50` 低模，<9× 切回（滞回防抖）；沉陷对比/地层炸开期间自动回退高模；由 catalog `source_file` 推导静态地址，上传模型自动跳过 |
| GeoTIFF 底图 | 工具箱「分析 → 地形底图」 | 需先运行 `python scripts/preprocess_basemap.py`（UTM49N DEM → GK37 带重投影重采样 → `/static/models/basemap/`）；**交付包 DEM 实测有效区与矿区不重叠（偏东北约 25km），故未生成底图文件，功能正确降级为禁用** |

## 后端新增接口汇总

```
GET   /api/v1/projects/{id}/analysis/overview          统计概览
POST  /api/v1/projects/{id}/analysis/virtual-borehole  虚拟钻孔（IDW）
GET   /api/v1/projects/{id}/analysis/reserves?density= 工作面资源量估算
GET   /api/v1/projects/{id}/analysis/contours?layer=&step= 埋深等值线
GET   /api/v1/projects/{id}/boundaries                 井田边界/工作面折线
GET   /api/v1/projects/{id}/annotations                标注列表
POST  /api/v1/projects/{id}/annotations                创建标注
DELETE /api/v1/annotations/{id}                        删除标注
```

## 测试

- 后端 `pytest`：46 个用例全过（其中 `test_analysis_service.py` 18 个：厚度分布/深度分布/
  地层频率/工作面状态/虚拟钻孔插值/多边形面积与点在多边形/储量估算/IDW 网格/Marching Squares）。
- 前端 `npm run build`（vue-tsc）通过。
- 浏览器冒烟：项目中心 → 工作台加载合并地层 + 182 钻孔 → 统计概览/图例/边界/等值线
  （煤3-1：25~150m 共 6 级）/体积（合并模型 18.2 km³）/储量（89 圈闭共 1.16 亿吨）/场景保存 全部通过。
